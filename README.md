# Trabalho_3°_Trimestre

 ## Título do jogo: 
 Sugar Rush
 ## Narrativa/Tema:
Pegue os doces antes das crianças no Halloween enquanto elas tentam roubar os seus
## Ações do jogador: 
Andar, coletar
## Inimigos e/ou obstáculos:
As crianças irão atrás do jogador em sentido aleatório
## Itens e coletáveis:
Doces
## Condições de vitória: 
Sobreviver até o tempo limites enquanto coleta o máximo de doces
## Condições de derrota: 
Ser pego pelas crianças
## Progressão/dificuldade:
Com os doces adquiridos o jogador poderá receber atributos que irão o ajudar para chegar no tempo limite
## Referências visuais/estéticas: 
Vamos nos basear no jogo Candies 'n Curses
